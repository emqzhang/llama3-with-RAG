# llama3-evaluation

**Tech Stack**

Python, Ollama, Llama 3, LangChain, Chroma, Hugging Face

**Results**

Llama 3 initially got 3/5 questions incorrect. With retrieval, 3/4 questions were answered correctly, with the model declining to answer a founding-date question because the context didn't support it. Semantic issues surrounding "wine country" is the remaining error.
